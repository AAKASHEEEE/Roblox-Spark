# Action frame strips

One strip per library action, 8 frames evenly spaced over the action (u = 0..1), rendered with the engine renderer.
Props are grey-box placeholders named with the S4 anchor roles until S4's props land; mouths use the placeholder mouth states until S3 lands.

Regenerate: `node scripts/action-strips.ts`.
